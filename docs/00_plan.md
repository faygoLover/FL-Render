# FL Render — план (24.10.2026)

Общая клиентская библиотека для всей нашей графики: шейдеры, экранные проходы, совместимость с Oculus,
цветной свет от эффектов, единые настройки качества. Моды семейства перестают каждый по-своему решать одно и то же.

## Решения Alex (24.10)
- Название — **FL Render** (`flrender`, пакет `faygolover.flrender`).
- Настройки — своя вкладка в «Настройки графики» Embeddium (как у True Darkness, Sodium Extras).
- Сюда — всё наше, что связано с шейдерами и обработкой экрана. Исправление фонаря SA — сюда, только если оно
  пользуется методами библиотеки (сейчас нет: это проверка лучом в RP Fixes, остаётся там).
- Первый запуск — короткая проверка-определялка: картошка / нормальный / «NASA-PC» → пресет качества.
- На низком качестве — наши старые/запасные плоские способы (они уже есть в модах).

## Что было продублировано (до библиотеки)
| Что | Где |
|---|---|
| Определение шейдерпака Oculus (IrisApi через reflection) | ZA `LatePass.shaderPack`, Core `ShaderPack`, Portals `ShaderPacks` |
| Поздний проход после кадра шейдерпака | ZA `LatePass` |
| Глубина сцены в текстуру | ZA `SceneDepth` |
| Экранный цветной свет по глубине | ZA `AnomalyLight` (точки, 8), Portals `PortalLight` (прямоугольники, 4) |
| Свой PostChain поверх кадра на AFTER_LEVEL | Core `Interference`, Portals `PortalLight` |
| Поза камеры на AFTER_LEVEL | Core `GmOverlay.cameraPose` |
| Пресет качества + переключатели техник | только ZA `[graphics]` |

## Устройство
- **Качество**: `LOW` (простые плоские способы) / `MEDIUM` / `HIGH` / `ULTRA`. Каждый мод регистрирует свои
  **техники** (`FlRender.technique(modid, key, fromQuality)`): `AUTO` (по пресету) / `ON` / `OFF`.
  Файл `config/flrender.properties` (свой, потому что техники регистрируются модами динамически).
- **Вкладка Embeddium** «FL Render»: пресет + группа на каждый мод с его техниками (подписи из lang мода:
  `flrender.technique.<modid>.<key>` и `.tooltip`). Без Embeddium — только файл.
- **Автоопределение** (один раз, пока игрок сам не выбрал пресет): видеокарта (строка GL_RENDERER, видеопамять
  через NVX/ATI-расширения), ядра процессора, память Java → пресет. Затем первые ~10 с в мире: если FPS < 25 —
  пресет на ступень ниже (один раз). Сообщение в чат: что выбрано и где поменять.
- **Oculus**: `FlRender.shaderPack()`, `FlRender.shadowPass()`.
- **Поздний проход** (`LatePass`): моды регистрируют свои обработчики этапов; с шейдерпаком этапы мира
  запоминаются и проигрываются на AFTER_LEVEL после финального прохода Oculus; без пака — ничего не меняется.
- **Кадр готов** (`FrameHooks`): один раз за кадр — после сущностей (без пака) или в начале позднего прохода (с паком):
  глубина сцены → цветной свет → хуки модов (туман Дымки ZA и т.п.).
- **Глубина сцены** (`SceneDepth`): упакованная глубина одной текстурой на кадр, только если кому-то нужна.
- **Цветной свет** (`WorldLight`): моды отдают источники (точка или прямоугольник проёма), библиотека рисует всё
  одним проходом. Техника `flrender:world_light` с MEDIUM; источников: MEDIUM 4, HIGH 8, ULTRA 16.
- **Помощники**: `ScreenPass` (полноэкранный квад), `PostFx` (свой PostChain поверх кадра), `CameraPose`.

## Этапы
1. **FL Render 0.1.0** — всё из «Устройства». Сборка.
2. **ZA** — на библиотеке: свои LatePass/SceneDepth/ScreenPass/AnomalyLight → FL Render; `[graphics]` из
   `fl_zone_arts-client.toml` → техники FL Render (старые значения не переносятся — пресет новый).
3. **RP Core** (глаза: шары с MEDIUM, на LOW — плоские 0.8.6; помехи через `PostFx`) и **RP Portals**
   (свет — источники `WorldLight`; живой вид и снимок — техники, на LOW — сплошной цвет).
4. **Medicine / Psyche** — экранные эффекты через `PostFx` и техники (на LOW — проще); если Medicine уйдёт
   из слота постэффекта игры, исправление `AnomalyPostEffect` в RP Fixes станет не нужно.
5. **ХИСы (S5 Glow Sticks)** — переключатель подкраски в общей вкладке. Сборка в S5 Packs.
